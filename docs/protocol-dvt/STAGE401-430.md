## 423–428 Probability authority
No catch-success RNG formula was found in the DVT client path; this is server-side behavior.
The previous Kotlin formula (30% base + missing-HP bonus + level modifier, clamped 5–95%) had no DVT or original-server evidence.

The original PC server BattleAbstract.CatchPet provides:
rate = (1 - currentHp/maxHp) * 100
after its own level/catchability/capacity gates.

With DVT-specific gates already enforced separately, Kotlin now uses exactly the lost-HP fraction as success probability:
successRate = 1 - hp/maxHp
clamped only to the mathematical 0..1 domain.

This removes the invented level modifier and invented 5%/95% floors.
