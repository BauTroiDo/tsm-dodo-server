## 439–446 Current Kotlin mismatch
C:050 kind=2 reaches BattleAction.KIND_ITEM and BattleItemResolver.

BattleItemResolver currently supports recovery/revive/poison-style validation. For a non-recovery special item it rejects when resolveRecoveryEffect returns null. Therefore item 25085 does not currently have an evidence-backed catch implementation.

This is recorded as a real missing feature, not silently mapped to the manual catch branch.
